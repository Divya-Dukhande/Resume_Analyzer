# AI Resume Analyzer

## Introduction
AI Resume Analyzer is a web-based application designed to help students and job seekers analyze and improve the quality of their resumes using AI-powered analysis.
Users can upload their resumes, and the system analyzes the resume content to identify grammar and spelling mistakes, strengths, weaknesses, and other areas that can be improved. The application provides structured feedback and ATS-focused suggestions to help users create more professional and effective resumes. The system uses a React.js frontend with a Node.js and Express.js backend, an SQL database for storing analysis results, and Puter.js for AI-powered resume analysis. It provides a simple and user-friendly interface through which users can upload resumes and view their generated analysis and feedback.

## Key Features
- Resume analysis
- Grammar analysis
- Spelling analysis
- Strength identification
- Weakness identification
- Resume feedback
- ATS-focused improvement suggestions
- Analysis result storage and retrieval

## Technology Stack
- React.js
- Node.js
- Express.js
- SQL
- Puter.js

## System Workflow
1. User uploads a resume.
2. The application processes the resume.
3. Puter.js provides AI-powered analysis.
4. Grammar and spelling issues are evaluated.
5. Resume strengths and weaknesses are identified.
6. Feedback and ATS-focused suggestions are generated.
7. Analysis results are stored in the SQL database.
8. Stored analysis results can be retrieved for viewing.

## Benefits
- Reduces manual resume-checking effort.
- Provides quick feedback.
- Identifies grammar and spelling issues.
- Highlights resume strengths and weaknesses.
- Provides suggestions for improving resume quality.

## Conclusion
AI Resume Analyzer provides a convenient solution for automated resume evaluation by combining a React frontend, Node.js and Express.js backend, SQL database, and Puter.js AI functionality.
